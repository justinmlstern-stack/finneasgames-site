Support

Need help with TipTapTilt? We’re happy to help.

Contact us

Email support@finneasgames.com with a description of the issue. If helpful, include your device model and iOS version.

Common questions

The ball isn’t moving the way I expect.

Make sure your device is being held in the intended orientation. If TipTapTilt asks for access to motion-related device features, make sure that access is enabled.

The controls feel off-center.

Return the device to a comfortable neutral position and use the game’s recentering control before continuing.

I found a bug or something doesn’t look right.

Please email us with what happened and, if possible, a screenshot. We’ll use the information to improve the game.
