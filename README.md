# Finneas Games website

Static site for https://finneasgames.com

## Pages
- `/` — Finneas Games home
- `/numbertails/` — Number Tails
- `/numbertails/support/` — App Store Support URL
- `/numbertails/privacy/` — Privacy Policy

## GitHub Pages
Upload all files/folders in this directory to the root of your GitHub repository.
Then in the repository:
Settings → Pages → Deploy from a branch → `main` / `(root)`.

Set the custom domain to:
finneasgames.com

The included `CNAME` file should also contain:
finneasgames.com

## Contact address
The site currently uses:
support@finneasgames.com

If that mailbox/forwarder does not exist yet, either create it or replace that address in:
- numbertails/support/index.html
- numbertails/privacy/index.html
- all footer links
